# Cloudron packaging

This repository contains a Cloudron app definition (`CloudronManifest.json`, `Dockerfile`, `start.sh`).

## Build and install

1. Install the [Cloudron CLI](https://docs.cloudron.io/cli/) and log in to your Cloudron box.
2. Build the image from the repository root:

   ```bash
   cloudron build --set-version 2.0.7-1
   ```

   The command prints the resulting `image:<tag>` that you need in the next step.

3. Install on your Cloudron:

   ```bash
   cloudron install --image <tag>
   ```

The room dashboard is exposed through Cloudron's reverse proxy (port `3000` in the container). The SSB muxrpc/shs port is exposed via the `SSB_PORT` tcpPort in the manifest and defaults to `8008`. Keep the default to match the invites generated by the server.

Persistent data lives in `/app/data/ssb-go-room`.

## First admin user

Create the first administrator using the bundled `insert-user` helper:

```bash
cloudron exec -- /app/code/insert-user -repo /app/data/ssb-go-room @your-ssb-pubkey
```

This command prompts for a password that you can use to log into the dashboard.

## Configuration knobs

The start script automatically picks up Cloudron's `CLOUDRON_APP_DOMAIN` for `-https-domain`. Additional environment variables you can set with `cloudron env set`:

- `ALIASES_AS_SUBDOMAINS=false` (default): keep false unless you provision a wildcard certificate for `*.${CLOUDRON_APP_DOMAIN}`.
- `REPO=/app/data/ssb-go-room`: change if you need a different data directory.
- `LISTEN_ADDR_HTTP` and `LISTEN_ADDR_SHS_MUX`: container listen addresses (normally left untouched).

Cloudron handles TLS termination and forwards the required `X-Forwarded-*` headers automatically.
